# java-lotto-precourse

### 1. 로또 구매
- 로또 구입 금액을 입력받는다.
- 구입 금액에 해당하는 만큼 로또를 발행한다. (1장에 1,000원)
- 발행된 로또의 개수를 출력한다.
- 발행된 로또 번호를 오름차순으로 정렬하여 출력한다.
  - 각 로또는 1부터 45 사이의 중복되지 않는 숫자 6개로 구성된다.
- **[예외]** 구입 금액이 1,000원 단위가 아닐 경우 예외를 발생시킨다.
- **[예외]** 입력값이 숫자가 아니거나 공백일 경우 예외를 발생시킨다.

### 2. 당첨 번호 및 보너스 번호 입력
- 당첨 번호 6개를 쉼표(,)를 기준으로 입력받는다.
- 보너스 번호 1개를 입력받는다.
- **[예외]** 당첨 번호가 6개가 아닌 경우
- **[예외]** 당첨 번호에 중복된 숫자가 있는 경우
- **[예외]** 당첨 번호 또는 보너스 번호가 1~45 범위를 벗어나는 경우
- **[예외]** 보너스 번호가 당첨 번호와 중복되는 경우

### 3. 당첨 결과 계산 및 출력
- 발행된 모든 로또를 순회하며 당첨 번호와 비교한다.
- 각 로또의 당첨 등수를 결정한다.
  - 1등: 6개 번호 일치
  - 2등: 5개 번호 + 보너스 번호 일치
  - 3등: 5개 번호 일치
  - 4등: 4개 번호 일치
  - 5등: 3개 번호 일치
- 등수별 당첨 개수를 계산하여 당첨 내역을 출력한다.
- 총 투자 금액 대비 총 당첨 금액을 기준으로 수익률을 계산해 출력한다.
  - 수익률은 소수점 둘째 자리에서 반올림한다.
